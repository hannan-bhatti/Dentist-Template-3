# Vitalis Family Health & Integrative Polyclinic

A warm, human-centric client acquisition website template designed specifically for multi-generational family care centers covering **Family Medicine, Obstetrics & Gynecology, Pediatric & Adult Dental, Physiotherapy & Rehabilitation, Diagnostic Labs, and Preventive Cardiology**.

## Key Features
- **Warm Human-Centric Aesthetics**: Terracotta/Amber (`#b45309`), Botanical Emerald (`#065f46`), Soft Cream (`#fffbeb`), and clean modern layouts.
- **Interactive Family Wellness Plan Builder**: Bundle care packages (Maternal + Pediatric + Dental + Labs + Senior Cardiology) with live household discounts.
- **Interactive Maternal Due-Date & Trimester Roadmap**: For Gynecology patients: calculate estimated delivery dates and review recommended trimester scans and tests.
- **Multi-Generational Specialty Care Wheel**: Targeted pathways for infants, working parents, and senior elders.
- **Paperless Family Digital Registration**: Fast household pre-registration with zero waiting room paperwork and direct WhatsApp coordinator link.
- **Floating Family Care Desk**: Omnipresent contact concierge for rapid family appointments and triage.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Deploying to GitHub & Vercel

### Option 1: Direct GitHub Push
```bash
git init
git add .
git commit -m "Initial commit - Vitalis Family Health Template"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/vitalis-family-health.git
git push -u origin main
```

### Option 2: 1-Click Vercel Deployment
1. Push this directory to your GitHub account.
2. In the Vercel Dashboard, click **Add New > Project** and import the repository.
3. Vercel automatically detects Next.js and builds with zero extra configuration.
